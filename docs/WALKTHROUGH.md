# Photon Editor & Workspace Walkthrough

This walkthrough summarizes the major capabilities implemented across `photon-protocol`, `photon-storage`, `photon-image`, `photon-core`, `photon-plugins`, `photon-ipc`, `photon-ui`, `photon-panels`, `photon-canvas`, `photon-i18n`, `photon-browser`, `photon-viewer`, `photon-editor`, `photon-cli`, and `photon-desktop`.

## Summary of Capabilities

### 1. Selection Suite, Selection-Clipped Brush/Eraser & Free Transform
- **Selection & Masks**: `SelectionMask` ([selection.rs](../crates/photon-image/src/selection.rs)) supports Marquee (`M`), Freehand/Polygon/Magnetic/Bézier Lasso, Magic Wand (`W`), Quick Select, Color Range, Quick Mask (`Q`), boolean ops, `SelectionModify` dialog, and `Nearest`-sampled GPU marching ants (`sel_sampler`).
- **Live Stroke & Clipping**: `Brush`/`Eraser` live strokes clip to `SelectionMask` (with feathering), offset layers, and layer transparency masks (`document.rs`).
- **Selection-Aware Free Transform (`Ctrl+T`)**: Unclamped canvas handle hit-testing (`screen_to_image_px_unclamped`), premultiplied GPU inverse-affine preview, live transformed marching ants (`sample_sel_mask_at`), and mask/baseline preservation on expansion.

### 2. Multi-Stop Gradient Engine & Interactive Preview (`G`)
- Ported KogaView's multi-stop gradient engine (`render_gradient` / `render_gradient_on_mask` in [drawing.rs](../crates/photon-image/src/drawing.rs)): 6 shapes (`Linear`, `Bilinear`, `Radial`, `Square`, `Conical`, `Spiral`), 3 repeat modes (`None`, `Forwards`, `Alternating`), 7 blend modes, 4×4 Bayer dithering, selection clipping, and grayscale layer-mask rendering.
- Interactive `wgpu` preview with draggable start/end handles, `Shift` 15° snapping, `Enter`/`Esc` draft commit/cancel, 8 presets (`FG -> BG`, `FG -> Clear`, `Rainbow`, `Sunset`, `Ocean`, `Fire`, `Chrome`, `Vignette`), and interactive gradient stop editor.

### 3. Multi-Tab Editor, New Document (`Ctrl+N`), Unsupported Format Screen & Virtual Save As
- **Image Size & Canvas Size**: Moved out of the left tool rail into the **Image** menu and canvas context menu (`Ctrl+R` Image Size, `Ctrl+Shift+R` Canvas Size), opening as modal dialogs with `ColorPickerTarget::CanvasSizeFill`.
- **Multi-Tab Editor**: `document_tab_bar` below the Editor toolbar with `+` / `Ctrl+N` new document creation, virtual `Save As` for unsaved/new documents, Unsupported Format screen (`Command::OpenInEditorOrUnsupported` with `Back to Viewer` / `Back to Browser`), dirty indicators, per-tab view cache (`zoom`, `pan`, `crop_uv`, `tool`, `pending_adj`), dirty-close confirmation (`Ctrl+W`), and `Ctrl+Tab`/`Alt+1..9` switching.

### 4. Translate Plugin & Pipeline Parity
- **Model & Tessdata Resolution**: `resolve_models_dir_for` ([bridge.rs](../crates/photon-plugins/src/bridge.rs)) resolves plugin model directories consistently; OCR and Translate plugins pass `--tessdata-dir` to Tesseract.
- **Provider & Format Parity**: `TranslateProvider::GoogleWeb` is the default provider; `rasterize_for_translate` ([ai.rs](../crates/photon-core/src/ai.rs)) decodes non-standard image formats (`.jp2`/`.heic`/`.hif`/`.avif`/`.jxl`/`.kra`/Camera RAW) to temporary PNGs for OCR/translation and cleans up on drop.
- **KogaView Plugin-First Routing & Overlay**: KogaView plugin-first routing, `ViewerMessage::SwapTranslateLangs` with Tesseract↔ISO language mapping, block-merge and per-path caching, rotated/Dual/Manhwa overlay rendering, `⋮⋮` drag handles, bottom-centered `result_card`, and full-box text masking with high-contrast `pal.text_primary`.

### 5. Popup/Dialog & Menu/Icon Polish
- **Dialog Sizing & Resize**: `resolve_card_and_body_limits` ([frame.rs](../crates/photon-dialogs/src/frame.rs)) clamps dialog card and scrollable body dimensions cleanly across viewport sizes alongside 8-way resize handles.
- **Menus & Icons**: `MenuEntry::IconRow` and `opaque(scrollable(...))` in `photon-ui` ([menu.rs](../crates/photon-ui/src/menu.rs)), `Icon::BookOpen` (`ReaderOptions`) and `Icon::PanelsTopLeft` (`Filmstrip`) in [icons.rs](../crates/photon-ui/src/icons.rs), Quick Access header pencil Edit toggle, and responsive `ReaderOptions` popup.

### 6. Extended Codecs & Hybrid Archive/PDF (`ArchiveSession`)
- **Native & Extended Codecs**: Added `.jp2`/`.j2k`/`.jpx`/`.jpf` (`libopenjp2`) and `.heic`/`.heif`/`.hif` (`libheif`) via [native_codecs.rs](../crates/photon-image/src/native_codecs.rs), `avif-native`, 29 `rawler` Camera RAW formats, `.kra` (Krita), and `.icns` (`image/x-icns` in [codec.rs](../crates/photon-image/src/codec.rs) via `extract_icns_best_payload`).
- **Hybrid Archive/PDF**: `ArchiveSession` ([archive.rs](../crates/photon-image/src/archive.rs)) indexes `.cbz`/`.zip`/`.pdf` pages lazily and materializes requested pages on demand, paired with a windowed Filmstrip in Viewer and Open / Edit / `xdg-open` actions in Browser. The Filmstrip and Browser grid are virtualized: only the visible range (+`FILMSTRIP_VISIBLE_OVERSCAN` / `VISIBLE_OVERSCAN_ROWS`) is scheduled for thumbnails, the strip scrolls itself to follow the active page on open/next/prev, and its range is recomputed on window resize so newly revealed thumbs load without a scroll event.

### 7. 3-Process Architecture & Linux Taskbar Separation
- **3-Process Routing**: `compute_launch_route` ([main.rs](../crates/photon-desktop/src/main.rs)) routes launches across:
  - **Browser singleton** (`photon.sock`)
  - **Editor singleton** (`editor.sock` via `AppPaths::editor_socket_path`)
  - **Viewer multi-instance** (`v-<pid>.sock` + `CanonicalPathLock` focus+restore deduplication)
- **Viewer Toolbar & Linux Taskbar Grouping**: Viewer toolbar groups `[ Browser | Editor ]` and `Filmstrip → Fullscreen → View Adjustments → Info`. Below ~720 px the four toggles collapse into a single `…` dropdown (same order, Info last). `window_app_id_for` ([app.rs](../crates/photon-desktop/src/app.rs)) sets distinct `application_id` / `StartupWMClass` values (`io.github.tienv2i.Photon`, `io.github.tienv2i.Photon.Editor`, `io.github.tienv2i.Photon.Viewer`) matching the 3 `.desktop` templates and MIME defaults in [scripts/install.py](../scripts/install.py). Each role also ships its own icon name (`io.github.tienv2i.Photon` grid, `.Viewer` framed photo + lens, `.Editor` sliders) so taskbar and app-menu entries are visually distinct.

### 8. UI Polish, Cascading Context Submenus & Dialog Standardization
- **Cascading Plugin Context Submenus**: `with_context_menu_and_submenus` ([menu.rs](../crates/photon-ui/src/menu.rs)) renders multi-level menus (`Plugins > <Plugin> > <Actions>`) in Browser ([photon-browser/src/lib.rs](../crates/photon-browser/src/lib.rs)) and Viewer ([photon-viewer/src/lib.rs](../crates/photon-viewer/src/lib.rs)), while `estimate_menu_height_with_spacing` prevents bottom-edge clipping for context menus and `ActiveMenu::EditorAddLayer` (with a captured `editor_add_layer_anchor` so the menu stays anchored instead of following the cursor).
- **Browser Long-Filename Clipping & Batch Custom Folder**: Added `.width(Length::Fill).clip(true)` across Browser Grid/Details/List/Explorer rows ([grid.rs](../crates/photon-ui/src/grid.rs), [table.rs](../crates/photon-ui/src/table.rs), [button.rs](../crates/photon-ui/src/button.rs), [photon-browser/src/lib.rs](../crates/photon-browser/src/lib.rs)), and added `BatchInputMode::{Selection, CurrentFolder, CustomFolder}` with folder-picker wiring in [batch_dialog.rs](../crates/photon-browser/src/batch_dialog.rs).
- **Dropdown Standardization, Wider Curves & Layers Blend Row**: Added shared `pick_list_style` / `pick_list_menu_style` ([theme.rs](../crates/photon-ui/src/theme.rs)), converted multi-option selectors in Batch Convert/Resize/Crop, Adjust Curves (`360×360` plot inside `500×650` dialog, `label-general-presets`), New Document, and Resize dialogs to `pick_list`, and moved the Editor Layers panel `blend_picker` into a full-width row above `opacity_row` ([photon-editor/src/lib.rs](../crates/photon-editor/src/lib.rs)).

### 9. Viewer Edge Navigation, Dual/Webtoon/PDF Marquee & OCR/Translate Fixes
- **Transparent Hover-Reveal Edge Navigation**: Added `56.0`-px left/right edge Next/Back zones in `Single` and `Double` modes (RTL-aware in Manga mode, disabled during `Space` pan and `Translate`/`OcrOnly` marquee tools) in [photon-viewer/src/lib.rs](../crates/photon-viewer/src/lib.rs).
- **Dual, Manga & Webtoon Marquee Alignment**: Normalized `sel_preview_rect` against `effective_doc_size()` in [photon-canvas/src/lib.rs](../crates/photon-canvas/src/lib.rs) and un-mapped `ContentFit::Contain` letterboxing on Webtoon marquee release in [app.rs](../crates/photon-desktop/src/app.rs).
- **PDF Toolbar Sync, Translate Rasterization & Linux MIME Types**: Removed the duplicate archive filename pill from the Viewer toolbar, added `ensure_archive_page_for_path` before `viewer_translate` and enabled `rasterize_for_translate` for `.jp2`, `.pnm`, `.jxl`, `.avif`, `.heic`, `.svg`, `.psd`, and RAW formats in [ai.rs](../crates/photon-core/src/ai.rs), and added `MimeType=@MIMETYPES@` (including `application/pdf`, `application/zip`, `.jxl`, `.jp2`, `.svg`, `.psd`, `.kra`, RAW) to [io.github.tienv2i.Photon.desktop.in](../packaging/linux/io.github.tienv2i.Photon.desktop.in) and [scripts/install.py](../scripts/install.py).

### 10. Phase 1: UI/Font Scaling, Context Menus, 2-Line Sliders & Browser/Viewer Polish
- **Bottom-Anchored Context Menus & L3+ Cascading Submenus**: Flipped context menus anchor cleanly to the cursor bottom (`menu.rs`), and cascading submenus at level 3+ preserve horizontal flip direction and row-anchor alignment.
- **2-Line Slider + Steppers**: Added reusable 2-line slider+stepper controls (`photon-ui/src/panel.rs`) across Editor tool options, adjustments, and dialogs for compact, unambiguous numeric entry.
- **Live UI/Font Scale, Display Font & GNOME Fractional Scaling**: Added live `UI Scale`, `Font Scale`, and `Display Font` settings (`photon-ui/src/typography.rs`, `photon-desktop`) with GNOME fractional scaling support.
- **Viewer Edge Nav Auto-Visibility & Browser Edit/Plugin Normalization**: Viewer edge navigation auto-hides when the image fits or does not overflow; Browser gained an **Edit** menu and normalized, concise plugin/action labels across manifests and menus.

### 11. Phase 2: Photoshop-Aligned Shortcuts, Tab Context Menu, Duplicate Image & Smart Paste
- **Photoshop-Aligned Shortcuts & Editor Menus**: Aligned Editor keyboard shortcuts and menu organization with Photoshop conventions, and added a Document Tab context menu (Close, Close Others, Close Right, Duplicate).
- **Duplicate Image, New from Clipboard & Smart Paste**: Added **Image → Duplicate Image**, **New from Clipboard** in the New Document dialog, and **Smart Paste** with interactive placement/scaling options.

### 12. Phase 3: Non-Destructive Vector & Text Layers, Path Tools, Transform Each & Vector Blend
- **Non-Destructive Vector Layer & Path Tools**: Added `LayerKind::Vector` (`V` badge), `VectorLayerData` (`Path`, `Rect`, `Ellipse`, `Polygon`), **Path Select** (`A`) for direct anchor/Bézier handle editing, **Pen** (`P`) and **Shape** (`U`) creation/editing, and `.ora` / CPU rasterization integration.
- **Vector Menu, Transform Each & Vector Blend**: Added a **Vector** menu with **Transform Each…** (scale, rotate, translate, reflect, 9-point `CanvasAnchor`, `Repeat Step`, and `Apply to Duplicate`), **Vector Blend…** (interpolated multi-step shape blending), **Convert Shape to Path**, and **Rasterize Layer**.
- **Non-Destructive Text Layer & Text Tool**: Added `LayerKind::Text` (`T` badge), `TextLayerData` (text, font family, size, color, alignment, line height, bold/italic, box width, position), interactive **Text Tool** (`T`), and `usvg`/`fontdb` + procedural fallback rasterization (`photon-image`).

### 13. Release `0.0.1-beta`: Plugin Hooks, Viewer Startup Modes, Editor UX & Linux Packaging
- **Manifest-Driven Plugin Hooks & Quick Actions**: Replaced hardcoded plugin UI with manifest-driven Quick Actions (`slot: "quick"`), per-plugin Quick Action visibility toggles, `Plugins` tab in 5-tab Settings (`General`, `Viewer`, `Browser`, `Editor`, `Plugins`), batch Browser quick actions, and standalone `Remove Gemini Watermark` + `OCR` / `Translate` / `AI OCR` plugins.
- **Viewer Modes, OCR/Translate & Startup Policy**: Added `Viewer Single/Multiple Instance` setting, 5 `SystemOpenWindowMode` startup modes (`FitImage`, `Maximized`, `FixedSize`, `Remembered`, `Fullscreen`), auto-hiding bottom status bar when the image's bottom edge overlaps it until hovered (`viewer_status_bar_overlaps`), fixed Manhwa (`Webtoon`) region scan & active page sidecar targeting, and restored original source paths after `.jp2`/RAW/JXL rasterization in `photon-core`.
- **Editor UX & Selection-Scoped Adjustments**: Added **Open** quick action on toolbar, shortcut hints across all Editor tool strip tooltips, live GPU Move (`V`) preview while dragging, fixed-center brush resize (`Shift+Drag`), `Ctrl`/`Alt` quick eyedropper cursor + pipette overlay, **Liquify** (`Ctrl+Shift+X`) in **Filter** menu, and **Selection Only / Ignore Selection** scoping in Color & Light, HSV, Color Balance, Curves, and Denoise dialogs (`apply_with_selection`).
- **Linux Desktop Integration & Packaging**: Removed `MimeType` from `Photon Manager` (`io.github.tienv2i.Photon.desktop.in`) while keeping image MIME types for `Photon Editor` and image+archive MIME types for `Photon Viewer`; added `.deb`, `.rpm`, Arch `.pkg.tar.zst`, `.flatpak`, and `.AppImage` release packaging and GitHub Actions workflows.

### 14. Release `0.0.3-beta`: Saved Selection Channels, Rulers/Grid/Guides, Crop & UX Ergonomics
- **Saved Selection Channels (`Save Selection…` / `Load Selection…`)**: Added `SavedSelectionChannel` storage inside `SelectionMask` (`photon-image`), `SavedSelectionSummary` in `EditorSelectionSummary` (`photon-protocol`), and `EditorSaveSelection` / `EditorLoadSelection` / `EditorDeleteSavedSelection` commands in `photon-core` with Replace/Add/Subtract/Intersect and Invert options.
- **Synchronized Rulers, Guides & Grid Settings**: Aligned `EditorRulerProgram` ([workspace.rs](../crates/photon-editor/src/workspace.rs)) to `PhotonCanvas::fit_geometry` via `CanvasEvent::ViewportResized`, added live drag-to-create guide previews (`pending_guide_preview`), resize hover cursors on guides, **View → New Guide…** (`px`/`%`), and **View → Grid Settings…** + **Settings → Editor → Grid & Guides** (`grid_spacing_px`, `grid_subdivisions`, `grid_opacity`).
- **Crop, Clipping Mask, Recovery & Ergonomics**: Fixed `initial_crop_uv_from_editor` to unpack `[x, y, width, height]` bounds accurately, added Clipping Mask, Crop dimmed overlay + 8-handle resize + `X/Y/W/H`, Resize/Canvas presets, app-exit unsaved tracking & crash recovery, Photoshop-aligned `Shift`/`Alt` Marquee disambiguation, `Enter`-to-Apply across tools/dialogs, auto-focus on first dialog/tool inputs, visual SVG icons for Rulers/Grid/Guides/Snap/Align & Distribute, and prevented Settings/Dialog modal stacking.
